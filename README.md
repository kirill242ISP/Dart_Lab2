## Ответы на вопросы

1. **В чём разница между полем класса и обычной переменной в функции?**
   Поле класса принадлежит объекту и хранится в нём, доступно через `this`. Обычная переменная существует только во время выполнения функции и недоступна извне.
2. **Что такое конструктор и зачем он нужен?**
   Конструктор — специальный метод, вызываемый при создании объекта. Он инициализирует поля объекта начальными значениями.
3. **Зачем нужен @override перед toString()? Что будет если его убрать?**
   `@override` — аннотация, проверяющая, что метод действительно переопределяет метод родителя. Без неё код скомпилируется, но компилятор не предупредит об опечатке в имени метода.
4. **Чем статическое поле static int \_counter отличается от обычного поля? Сколько копий этого поля существует в программе?**
   Статическое поле принадлежит классу, а не объекту. Существует **одна** копия на всю программу. Обычное поле — своя копия у каждого объекта.
5. **Что означает нижнее подчёркивание в \_counter?**
   `_` делает идентификатор приватным для файла (library privacy). Доступ к `_counter` возможен только внутри файла `todo.dart`.
